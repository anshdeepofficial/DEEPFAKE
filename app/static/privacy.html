Privacy

DeepGuard is designed so the operator can understand where data goes. This page describes the default repository behaviour; a third-party deployment may add its own infrastructure or logging.

Short version

Media uploads are processed by the DeepGuard server. The built-in heuristic detectors do not intentionally retain uploaded media after a request finishes. Claim verification sends claim text to public search providers and, if the operator configures it, Google Fact Check Tools. Optional external trained-model forwarding is disabled by default.

Media analysis

Images and audio are processed in server memory. Video analysis uses a temporary server-side file that is deleted after analysis. The application does not intentionally write uploaded media to a permanent user library or database.

Claim verification

The claim text and search query may be sent to the configured search provider so evidence can be retrieved. If GOOGLE_FACT_CHECK_API_KEY is configured, the claim can also be sent to Google Fact Check Tools. The source page URL and title can be included as context.

Optional trained-model services

External model forwarding is disabled unless the server operator explicitly enables it with DEEPGUARD_ENABLE_EXTERNAL_MODELS=1 and configures a model endpoint. When enabled, the relevant uploaded file is sent to that configured model service.

Logs

Default application logs contain operational events and errors, not uploaded media contents. Hosting providers may record IP addresses, timestamps, request paths and infrastructure logs under their own policies.

Browser extension

The extension reads the current page only after a user action. For selected-text verification it sends the selected claim, page URL and title; it does not send the full page body. Full-page verification sends a bounded portion of visible article/page text so DeepGuard can extract a claim.

Retention

The default application contains no database for uploaded media or verification history. Operators should document any additional retention they add at the hosting, proxy, analytics or model-service layer.

Research software. Review this policy again before a public production launch if you add analytics, accounts, cloud storage or third-party model APIs.
